PLAIN ENGLISH

Every term on the map, in one line.

Plain English for the technical words above.

n8n
The automation tool the client workflows run in: triggers, waits, branches and actions, wired as nodes.
Webhook
A web address another system calls the moment something happens, which starts a workflow.
Hermes
My own AI agent on a server, reachable from Telegram. It remembers, reads my notes and runs jobs unasked.
Telegram
The chat app I use to message Hermes and to get alerts.
Knowledge base
My searchable library of notes and documents, split into 1,277 short passages.
Spec
A short written brief: the outcome, the limits, the files and the checks, agreed before building.
Acceptance criteria
The checks a result must pass to count as done, written before the work starts.
Claude Code
The AI coding tool that builds: it reads and writes real files and runs commands.
Subagent
A helper Claude Code starts for one part of a task, so several parts are worked on at once.
VS Code
Visual Studio Code, the code editor I use to read what was written and take over by hand.
Codex
A second AI model that reviews the work. A fresh reviewer catches what the author missed.
Skill
A reusable procedure an agent loads for one kind of job, like drafting an article or cutting a reel.
Agent
An AI assistant with one job. It picks its own tools and finishes the task.
Router
The step that reads a job and hands it to the right specialist.
Approval gate
A hard stop. Nothing reaches a client, a repo or a send button until I approve it.
Handover doc
The same short document with every delivery: what it does, what breaks it and who to call.
Write back
Putting the result onto the client’s contact record, so the next run knows what already happened.
Commit
A saved, labelled snapshot of code changes.
Deploy
Putting the new version live: Vercel for sites, Docker on my VPS for Hermes and the workers.
Roll back
Putting the last good version back up when a live check fails.
VPS
A private server I rent, where Hermes and my workers run.
Fold back
Turning a mistake into a written rule, so it does not happen twice.
Fresh session
Starting the next task in a clean AI session instead of a long, cluttered one.
