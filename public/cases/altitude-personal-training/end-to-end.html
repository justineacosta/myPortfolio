From Start coaching to the next block

Every trigger, flow, bot and agent behind Altitude’s site, wired as one graph: an application and a visitor’s questions, the free consult, a plan started only on Elias’s yes, the first week, the Sunday check-in, form reviews and the review at the end of every 4 weeks.

Elias approves anything Claude drafts for a client’s inbox and writes every check-in reply himself, and no subscription starts until he marks the consult Starting.

PLAIN ENGLISH

Every term on the map, in one line.

Plain English for the technical words above.

n8n
The automation tool the application flow and both agents run in.
Make
The automation tool starting a plan runs in: it watches for a consult marked Starting.
Zapier
The automation tool the Sunday check-in runs in, as two Zaps.
Webhook
A web address the application calls the moment it is sent, which starts AL-01.
Claude
Anthropic’s AI model. It summarises, answers, prepares and drafts here, and never writes a check-in reply.
Airtable
Where Altitude keeps its applications, plans, clients, check-ins and form notes.
Stripe
Where each client starts their monthly subscription, on Stripe’s own page.
Cal.com
The booking tool that holds Elias’s calendar, the consult and the assessment.
Gmail
The mailbox the templates and approved block reviews are sent from.
Telegram
The chat app where Elias gets summaries and preps, forwards form videos and approves drafts.
Supabase
The database that stores the passages the Program Q&A bot searches.
Passage
A program, a plan or a question cut from a longer page, as the search returns it.
Template
A fixed message with blanks for the name, plan and times. No AI writes it, so it may send alone.
Consult
The free 20-minute call with Elias about fit, format and price.
Starting
The status Elias sets after the consult, with the plan chosen. It is his yes for the payment link.
Payment link
A Stripe Checkout page for the plan’s monthly subscription. It lasts 24 hours.
Assessment
The 60-minute movement screen and baseline numbers, in the studio or over video.
Coaching app
Where sessions, form videos and Elias’s replies live. No flow reads or writes it.
Block start
The day a client’s first block began, which Elias enters in Airtable.
Check-in
The Sunday form: sleep, steps, bodyweight trend and how training felt.
Form notes
An Airtable table of each form review prep, with the line Elias adds after each review.
Re-test
The numbers taken again each block. They live in the app, so Elias adds them himself.
Agent runs
The Google Sheets tab where every agent run, tool call and yes is logged.
Approval gate
A hard stop. No subscription starts and no block review is sent until Elias says yes.
Agent
An AI with one job that picks its own tools, one call at a time, until the job is done.
A worked example. Altitude is a fictional coaching studio, not a client project, and figures are illustrative.Built by Justine Acosta
