# Notes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Notes section of client-facing guides, written in MDX, shipped switched off, with three draft posts for Justine to edit and publish.

**Architecture:** `data/notes.ts` is the post list (plain TypeScript), and `content/notes/<slug>.mdx` holds each body. `app/(site)/notes` has an index and a `[slug]` route that dynamically imports the MDX, with layout in `components/notes/`. The nav, sitemap, ⌘K and Lumen read only `publishedNotes()`, and only while `/notes` is visible.

**Tech Stack:** Next.js 16 App Router with `@next/mdx`, React 19, Tailwind 4, Vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-13-notes-design.md`

## Global Constraints

- Branch `feat/notes`, stacked on `feat/san-fernando-case-study`.
- New packages: exactly `@next/mdx`, `@mdx-js/loader`, `@mdx-js/react`, `@types/mdx`. No remark or rehype plugins, and no typography plugin.
- Before writing MDX config, read `node_modules/next/dist/docs/01-app/02-guides/mdx.md` and `.../03-api-reference/03-file-conventions/mdx-components.md`, as AGENTS.md requires.
- `/notes` ships `hidden: true`, and all three posts ship `draft: true`.
- Posts: no invented figures, results or quotes. Samples are named as samples (fictional businesses). Only San Fernando is client work, using only facts from SanFernandoWeb's README and `projects.caseStudy`.
- Site copy uses no em dashes in new strings. (V3's are kept only where ported verbatim, and there are none here.)

## Review Focus

1. **A draft reached in production by URL** (`/notes/<draft-slug>`): must return the 404. Pinned in Task 3 through `generateStaticParams`, and in Task 5's e2e.
2. **`/notes` hidden but a post is published:** the post route must still 404, and sitemap, ⌘K and Lumen must list nothing. Tested in Tasks 3 and 4.
3. **An internal Markdown link inside a post** (`[the case study](/projects#san-fernando)`): it must go through `ShellLink` (the crossfade, the hash view opening). External links get `rel="noopener"`. Tested in Task 0.
4. **Contact hidden:** a post's "Start a project" link disappears. Tested in Task 3.
5. **A long title on a 390px phone:** no sideways scroll on the index or a post. Tested in Task 5, once published, and in the dev-preview check in Task 5 Step 3.
